# 🎬 CineGo Backend

Backend API for the **CineGo** movie ticketing system.  
Built with:

- Node.js
- Express.js
- Sequelize ORM
- PostgreSQL16
- JWT Authentication
- Swagger API Documentation

---

# Clone Project

```bash
git clone https://github.com/lean2708/cinego-backend
cd cinego-backend
```

# Install Dependencies
```bash
npm install
```


# Start server:
- You need to create the env file first
```bash
npm run dev
```

# Swagger Documentation (Local)
```bash
http://localhost:8080/api-docs
```
